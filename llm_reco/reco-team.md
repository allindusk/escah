# 推荐 v0.3（配队 + 副本/BOSS 对策，独立推导）

> 在 v0.2「单卡强度」基础上，结合**讨伐战/副本机制**与**编队接力系统**，给出可落地的配队方案。
> 数据来源：`raid.md`（各 BOSS 参数，事实）、`raid-formations.md`（编队机制，事实）、`char_data.json`（角色机制，已核验）。
> **依然不参考** `raid-recommended.md`（官方推荐名单）。本版结论由"BOSS 机制需求 → 所需对策机制 → 角色数据匹配"推导。
> 配套推理见 `reasoning-log.md`（v0.3 增补节）。

## 0. 先纠正一个根本误解：上场 5 人 ≠ 单队决战

`raid.md` 关键事实：
- **体力每秒扣 2%**（无续航 50 秒全退场），且该费用为百分比——**体力/双防数值完全无效**，高血量与高防在 raid 里没用。
- 战斗**无时间限制**，单队打不完，因此高分打法是**多队接力**：`优先1`(5人) → `优先2`(15人) → `替补` → `星面50人编队`。
- "分队伍"的真正含义是**接力轮换**，不是同场多队。我的配队建议必须给出"首发队 + 接力队"结构，而不是只列 5 人。

## 1. 配队铁律（从 raid 机制推出）

| 铁律 | 推导 |
|---|---|
| **减伤率 debuff（降防）>> 攻击 buff** | 面对 75% 减伤 BOSS，降防带来的伤害提升是攻 buff 的 **3 倍**；60% 减伤时为 1.5 倍。仅 50% 减伤的古纳冈两者等价。→ 优先堆降防到 80%+，其次攻 buff |
| **单体 + 领域同名效果叠加生效** | 同类多角色放同款只取最高（浪费）；但"角色单体型"与"领域型"叠加。→ 一单体一领域搭配最高效 |
| **必杀充能辅助是得分核心** | FEVER 中必杀发动次数=得分主来源；不早点出必杀=全队裸装。→ 充能/提速位是刚需 |
| **默认带治疗** | 除非防御叠到 100% 减伤（受 1 点伤害）否则要奶；持续治疗 > 一次性群疗 |
| **BREAK 比控时更值** | 破防灯亮=BOSS 眩晕+1.5 倍伤害+重置攻击计时；时间停止收益保守。→ 带"确定点灯"角色优于纯时停 |

## 2. 通用 5 人首发模板（适合多数 BOSS）

```
[主输出] 单体高倍率必杀（自带降防/攻buff/充能 更佳）
[生存辅助] 防御buff 或 BOSS降攻 debuff（单体+领域叠到 50%+）
[输出辅助] 降防 debuff 或 攻buff（叠到 80% 减伤降低）
[治疗] 持续回复型（兼免控/解控最佳）
[自由位] 追加输出 / 必杀充能 / 提速 之一
```

**角色落位（全部来自 v0.2 已核验数据）：**
- 主输出：ブライドハルカ・リバース(不撤退+攻521+即死) / 超昂閃忍ナリカ(复活+双修) / 閃忍マユリ(R, 15×无视防御核弹)
- 生存辅助：ビートアミュレット・ノノノ(R, 全队攻防±30) / 神騎アルゴル(R, 速度场+全队充能)
- 输出辅助（降防核心）：鬼の斗羽大洋(SSR, 全体攻防−60%！顶级减益) / 魔女ミヤビ(SSR, 敌方防速−20%)
- 治疗：制服ニャンコ(SSR, 免控领域+治疗) / 六の法杖セラフィール(SSR, 被动解控+治疗) / 魔女シズク(R, 廉价群疗)
- 自由位：妹の1024(SSR, 充能核心) / 真夏のイーイー(SSR, 攻击buff+眩晕抵抗)

> 减伤降低凑不到 80% 时，把"输出辅助"位再塞一个降防手（如 神騎ハニーエル R 的魔免+免疫，或第二降防角色）。

## 2b. 团队构建方法论（v0.4）：如何从 370 角色里挑出 5 人均衡队

> 用户追问：光比输出不够，还要**生存**（治疗/减伤/免控）和**增益**（攻击速度、必杀充能非常重要），但**同场只上 5 人**。怎么从 370 人里调出一队"输出+生存+增益齐全"？
> 方法不靠官方名单，靠对 `char_data.json` 全量打"队伍职能标签"后做覆盖分析（脚本 `_team_build.py`，产物 `_team_build.txt`）。

### 2b.1 核心矛盾：5 框塞不下"5 个单职专家"
一个 raid 均衡队**最少**要覆盖 5 个职能：输出、降防、速度、充能、治疗（生存）。若每人只干一件事，需要 ≥6 槽——**超出 5 人上限，不可能**。
**唯一解法 = 职能密度**：挑"一人兼多职"的角色，把多个职能压进 5 框。

### 2b.2 全量职能稀缺度（char_data.json 实测，持有角色数）
| 职能 | 总数 | SSR/SR/R | 含义 |
|---|---|---|---|
| 不撤退 | **8** | 3/1/4 | 极稀缺，raid 居座/高难主线神 |
| 复活 | **1** | 1/0/0 | 全游戏唯一（超昂閃忍ナリカ） |
| 降防 | 46 | 41/1/4 | raid 进攻核心，偏稀缺 |
| 解控 | 19 | 16/0/3 | 中稀缺 |
| 增伤 | 54 | 49/1/4 | 进攻放大器 |
| 减伤 | 60 | 50/1/9 | 生存主力 |
| 免疫 | 62 | 46/1/15 | 免控领域 |
| 治疗 | 99 | 76/8/15 | 生存刚需 |
| 充能 | 102 | 82/4/16 | 用户强调：FEVER 得分核心 |
| 速度 | 126 | 96/6/24 | 用户强调：行动次数 |
| 攻buff | 110 | 95/4/11 | 进攻加分项 |
| 硬控 | 112 | 80/5/27 | 确定点灯（BREAK） |
| 输出 | ~全 | — | 高倍率必杀≈人人有，从不缺 |

**读表**：真正卡脖子的稀缺职能是 **不撤退(8)/复活(1)/降防(46)**；速度/充能虽用户强调"非常重要"，但持有量充足（126/102），**可轻松塞进队伍**，关键是选"同时带速度/充能 + 别的职能"的高密度角色。

### 2b.3 职能密度：370 人里有多少人"一人顶多人"
- 覆盖 **≥3 职能**：46 人
- 覆盖 **≥4 职能**：37 人
- 覆盖 **≥5 职能**：10 人
- 覆盖 **≥6 职能**：7 人（如 小鬼の斗羽大洋：免疫+减伤+治疗+硬控+输出+降防，单卡顶 6 职）

→ 池子足够大，**5 框塞满齐全队伍完全可行**，关键是优先选高密度卡。

### 2b.5 给用户的"挑选流程"一句话总结
1. 先列"必覆盖清单"（输出+降防+速度+充能+治疗+1项生存保险）。
2. 在 `char_data.json` 按职能标签筛，优先**密度≥3**的卡填稀缺职（不撤退/复活/降防）。
3. 用余槽补"速度/充能"——这两职能人多，专挑"顺带兼速度/充能"的高密度卡，别占用独立槽。
4. 5 槽排满后，多队接力照样按此模板复制（优先2/替补）。

## 4. 多队接力结构示例（以通用 BOSS 为例）

```
【首发 优先1】5人：主输出 + 生存辅助 + 降防手 + 治疗 + 充能核心
   → 目标：开场快速开 FEVER+BREAK（4.5倍窗口）
【接力 优先2】5人（同构或补降防/治疗）：
   → 首发退场后接管，维持降防覆盖与续航
【工具人（第6/7人，出击/退场即触发短时 buff）】：
   → 妹の1024(充能) / 真夏のイーイー(攻击buff) / 体育祭のヤブルー(全异常免疫+CC)
   → 短时效单体 buff 需配 超昂阿梅兹·幻梦 延长（高阶技巧，新人可暂忽略）
```

**新手节奏（raid-formations 步骤）：**
1. 先满突 1 套优先1（5人）：主输出(★5) + 降防 + 攻buff + 治疗(★3) + 充能(R)。
2. 再养优先2（5人）接力。
3. 给首发 5 人装备"重型星面"→等效多出一支编队（35-5-5-5 多星面结构）。

## 5. 副本维度（非 raid）

- **主线/EX 关**：有战斗时间限制、防御/魔抗**有效**，与 raid 规则相反。此处**站场+不撤退+高数值**更重要 → v0.2 的 不撤退/复活 角色（超昂閃忍ナリカ、ビートソニック・アキレス）通用价值高。
- **每日任务/宝箱狩猎**：效率优先，AoE 全体角色（247人）与提速充能辅助最实用。
- **高难本（暗影等）**：控制/解控需求高 → 免控领域（制服ニャンコ/魔女フタバ R）+ 解控（六の法杖セラフィール）。

## 6. 与 v0.2 的修正

- v0.2 把"攻击增益(3人)"列为 S 级；v0.3 修正：**降防 debuff（破防/贯通14人）在 raid 里比攻 buff 更核心**（75%减伤时价值3倍）。攻击buff 仍稀有但定位降至"输出辅助的加分项"。
- v0.2 单列"不撤退"为站场；v0.3 补充：**raid 里体力按百分比扣、双防无效**，不撤退的价值在 raid 中其实被稀释（不撤退≠不扣血，只是不强制退），真正适配 raid 居座的是"体力停止衰减"类（超昂奈理卡）。不撤退在高难主线才是真神。
- v0.3 新增"确定点灯"对策位（堕威大佛/乌塔尔专用），恰好 my v0.2 的 R 卡 エスカ・アメイズ/閃忍クサリ 命中此需求——印证独立推理自洽。

> 诚实留白：弗栗多/乌塔尔专用的"减速角色""全体异常清小猫"具体持有者需查 `raid.md` 减速表与角色全体必杀清单全量核实，本版仅给出机制方向与已核验示例。

## 5. 强度量化模型（v0.8 · RAID 专用 · 真实频率公式 · 真实觉醒表 · 真实两件配装）：单角色固定分 + 队伍考试式打分

> 用户要求：默认满星培养→**单角色强度是固定值，可建数学模型**；推荐时**算出能打多少伤害、施加多少 buff/debuff**（"分数就是伤害，像考试"）；新增角色只要读详情套模型即出分。
> 终局副本 4 种（raid / B宇宙 / 广域战 / 全域战），**本模型只攻破 raid**，其余三模式先占位（同框架接入只需换"场景常量+适配层"）。
> 为建通用模型，用户要求把除「角色 kit + 真实战斗细节」外的一切**全固定为常数**：BOSS（机制常亮·固定伤害·体力-2%/s·固定防御率 R）+ 角色（满星100级·觉醒+·觉醒属性强化满·**两件真实主装**）。R=0.50（古纳冈类）/ 连击阈值60%。
> **v0.7 修正（2026-07-30 用户给出真实觉醒表）**：v0.6 觉醒常数错误（速+3%除法/充+15pt）。真实规则：行动速度 **-0.1×20次=最多-2秒（扁平），强化下限 3sec**；必杀充能 **+0.3×20次=最多+6pt，强化上限 15%**（基础≥15 不受益）；攻/魔 +20%（全员同幅）。连击率+20(上限50%)不采用（50/70 档已达上限无收益；0 档点了反拖慢必杀）。
> **v0.8 修正（2026-07-30 用户拍板真实配装）**：删除全部副装贴片（多变量）与仁王纳豆（与部分角色技能效果冲突，多变量）。默认装备**仅两件主装**：火箭引擎/咆哮猛虎(满级) **行动速度 -50%**、冲击腰带(满级) **攻魔 +50%**。旧占位（主装+300 扁平 / 贴片B8降防30%·B1攻30%·B3速20%）全部作废——**降防不再有 30% 打底，只剩角色 kit 自带**。
> 实现：`llm_reco/_char_score.py`（只读 `char_data.json`，自动出分+分档+队伍打分）。**复用：新增角色补进 `char_data.json` → 重跑 `python llm_reco/_char_score.py`**。真实战斗细节（行動速度/必殺充填量/連撃率）由 `extract_chars.py` 抽 `詳細ステータス`。

### 5.1 单角色固定强度（Part1，场景全固定→强度只取决于 kit + 真实战斗细节）
**特征**（char_data.json 正则解析 + combat 真实字段）：`base=max(攻撃力,魔法力)`@lv100；必杀倍率（只认 canon「敵〇〇N倍」，觉醒取最大）；降防%/攻buff%/增伤%/guard%（文本正则）；**真实战斗细节**（extract_chars.py 抽 詳細ステータス）：`行動速度(sec)` / `必殺充填量(%)` / `連撃率(%)`；flag：奶/免疫/不撤退/复活/硬控/解控/减速。
**固定场景常量（均一行可改）**：FEVER=3 / CRIT=1.25 / BREAK=1.5 / 装备(火箭速-50%·腰带攻魔+50%，仅此两件) / 觉醒强化(真实表：速-2s下限3s/充+6pt上限15%/攻魔+20%) / **固定防御率 R=0.50（古纳冈类）** / 連撃阈值60%。
**损伤频率模型（battle.md 机制，分数即秒伤；v0.8 用真实数据+真实觉醒表+真实两件配装）**：
```
eff_speed   = max(行動速度(sec) - 2.0, 3.0)   # 觉醒扁平-2秒，强化下限3sec（已≤3无收益）
interval     = eff_speed × (1 - 火箭50%) / (1 + 自身速buff)   # 行动间隔(秒)
interval_ult= interval × (1 + 連撃率)         # 连击使行动计量条不前进→必杀/普攻节奏变慢
atks/s      = 1 / interval_ult
charge_eff  = 必殺充填量%≥15 ? 原值 : min(必殺充填量%+6, 15)   # 觉醒+6pt上限15%
必杀casts/s = (charge_eff/100) / interval_ult
combo_mult  = 1 + Σ 連撃率ⁿ×decay(n), decay=0.8/0.6/0.4/0.3(≥4击)   # 连击追加伤害(不暴击)
red_coeff   = 1 - 0.50*(1 - min(1, 降防))     # 降防只剩角色 kit 自带（副装已删）
crit = 1.25（腰带+50%全员常驻→稳定触发，全员一致不影响排名）;  break_m = 1.5 if 硬控 else 1.0
base_hit = base×1.20 × (1+攻buff+0.50) × (1+增伤) × red_coeff   # ×1.20=觉醒攻魔+20%；+0.50=腰带
normal_DPS = (base_hit·crit + base_hit·(combo_mult-1)) × atks/s      # 基础击暴击，连击追加不暴击
ult_DPS   = base_hit × 必杀倍率 × 3(FEVER) × break_m × 必杀casts/s
DPS = normal_DPS + ult_DPS
```
**辅助/生存分**（BOSS机制常亮→必须覆盖）：`100·复活 + 60·不撤退 + 40·免疫 + 35·奶 + 30·解控 + 25·硬控 + 30·guard%`。
**综合强度** = `0.70·DPS归一(0-100) + 0.30·UTIL归一(0-100)`；分档 **T0(前10%)/T1(前30%)/T2(前60%)/T3**。

### 5.4 诚实留白
- **觉醒强化（v0.7 已按用户真实觉醒表定死）**：速 -0.1×20=-2s 扁平(下限3s) / 充 +0.3×20=+6pt(上限15%) / 攻魔+20%。常数在 `_char_score.py` 顶部 `AWK_SPEED_SEC/AWK_SPEED_FLOOR/AWK_CHARGE/AWK_CHARGE_CAP/AWK_ATK`。注意：上限 3s/15% 是"强化不能越过的线"，非人人可达——强化次数有限（速最多-2/充最多+6）。
- **觉醒连击率 +20(上限50%) 未采用**：基础 50/70 档已达/超上限无收益；0 档必杀型点了 interval_ult×1.2 反拖慢必杀，理性不点。若想全员默认点满，改 kit_of 连击率一行即可。
- **装备（v0.8 已按用户拍板定死）**：仅两件主装——火箭 -50% 行动速度（乘法 `×(1-0.50)`，作用于觉醒后的 eff_speed）/ 腰带攻魔 +50%（与角色攻 buff 加算）。常数 `EQ_ROCKET_SPEED/EQ_BELT_ATK`。副装贴片与仁王纳豆按用户要求删除（多变量；纳豆与部分角色技能效果冲突）。火箭作用顺序（先觉醒扁平后装备乘法）为模型假设，若游戏实际是先乘后减，3s 下限角色数值会略变但排名几乎不动。
- **R=0.50（Step3 确认，古纳冈类）**：降防收益=攻buff 1 倍（R/(1-R)=1）；若改最难 75% 为基准，改 `R_ref` 一行，降防权重随 §7.6 升至 3 倍，排名微调。
- **连击率阈值 60%（Step3 确认）**：基础连击率只有 0/50/70 三档跳变，60% 仅命中 3 人；模型对连击用连续惩罚因子(interval×(1+連撃率))，不是硬二分类。
- 真实战斗细节来自 `char_data.json.combat`（extract_chars.py 抽 詳細ステータス），若源站数值更新重跑 extract 即可。
- 固定装备套数值（主装+300/副装三件套）据 equipment.md 合理设定；若实战标准配装不同改常量块即可。
- UTIL 点为主观稀缺度赋权；DPS/UTIL 0.70/0.30 为折中。队伍 `fit_mult` 为 BOSS 对策经验系数，非严格推导。
