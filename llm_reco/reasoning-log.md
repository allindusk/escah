## 0. 本次推理的边界与原则

我**故意不读取** `raid-recommended`（官方讨伐战强度榜）和 `beginner-guide`（官方新手指南点名）里的"推荐名单"。
原因：v0.1 把这些名单当成了结论本身，等于"别人说谁强，我就说谁强"——这是循环论证，且官方榜本身受版本、主观偏好、柯伊伯（Kuipor）当期卡池影响，并不等于机制上的客观强度。

我**只读取**：
- `char_data.json`：370 名角色的 五维 / 必杀技 / 固有效果（中日双语文本）。
- `game-mechanics.md` 中**系统机制类**的事实（伤害公式、intro、必杀连锁、装备"超昂金"等）——这些是规则，不是推荐。

我的立场：**强不强，由"机制在伤害/生存公式里的位置 + 该机制的稀有度 + 满突成本"决定**，不由任何榜单决定。

## 1. 第一步：把 370 个角色压成可比较的信号

370 人全文读不完，也没必要。我写了 `_signal_extract.py`，产出三类信号：

1. **总表**：每个角色的 稀有度 / 阵营 / 攻型 / 五维 / 获取 / 机制标签。
2. **五维榜 top20**：看属性上限与分布。
3. **机制分组**：按关键词把"拥有某类固有效果"的角色归到一起，数出每类有多少人。

> 局限说明（诚实记录）：机制标签是**关键词粗筛**，会有误报/漏报。例如"魔法buff"只命中 1 人，但核验原文后发现她其实是"敌方防速-20% 的减益"，并非给队友加魔法。所以我对关键候选又跑了 `_detail.py` 打印**完整原文**做二次核验——日志第 4 节的所有结论都基于核验后的原文。

## 2. 第二步：数据驱动的关键观察

### 观察 1：满级五维高度收敛，属性不是区分度
- 攻击上限 521、魔法上限 521、魔抗上限 522、体力上限 3200、防御上限 500。
- 绝大多数 SSR 的满级值是 **3050 / 500 / 475 / …**，大量角色完全相同。
- **推论**：在同为满级的前提下，A 比 B 多 21 点攻击，对伤害公式影响微乎其微。**真正拉开差距的是固有效果（机制），不是数值。** v0.1 按"攻击力排行榜"挑人，方向就偏了。

### 观察 2："不撤退"是极稀有的站场机制
全游戏仅 **8 人** 拥有"体力耗尽不撤退，直到受伤才离场"：
FM77(R)、神騎フローレル(R)、閃忍マユリ(R)、閃忍レイナ(R)、神騎プロキオン(SR)、ビートソニック・アキレス(SSR)、ブライドハルカ・リバース(SSR)、真夏のハルカ(SSR)。
- 其中 **4 个是 R/SR**——意味着新手用极低成本就能拿到"变相延长输出/站场时间"的核心机制。
- 在"体力随时间流失"的规则下，这直接对抗游戏的**核心失败条件**（退场=减员）。价值应给极高权重。

### 观察 3：速度辅助 / 充能辅助"极度普遍"，不能当稀有卖点
- 速度辅助：**126 人**。充能辅助：**105 人**。AoE 全体：**247 人**。
- **推论**：v0.1 把"闪忍彩香 300% 速度""神骑参宿四 全队充能"当成稀缺亮点，是受了官方榜的暗示。事实上 259 个 SSR 里一大半都带速度/充能。**R 卡的速度/充能价值，只在"新手还没有 SSR 辅助"时才成立**；满编老玩家眼里这只是通胀技能。
- 所以我给这类 R 卡的定位是"新手过渡/低成本补位"，而非"版本答案"。

### 观察 4：真正稀缺的是"攻击增益 / 魔法增益 / 破防 / 减伤 / 复活 / 全异常免疫"
- 攻击buff：**仅 3 人**（真夏のイーイー、魔女ミヤビ、黒門天・屍寺炎斎）。
- 魔法buff：**仅 1 人**（魔女ミヤビ，待核实幅度）。
- 贯通/破防：**14 人**。伤害减buff：**5 人**。异常解除：**19 人**。
- 复活：**仅 1 人**（超昂閃忍ナリカ）。全异常免疫：**仅 1 人**（体育祭のヤブルー）。
- **推论**：稀缺机制 = 高价值。这些才是"贵"的辅助/对策，应成为 S 级推荐的主体。

### 观察 5：异常免疫"领域光环"是免控位的性价比之王
一类角色的固有效果是"**自身在场期间，全队免疫某类异常**"（被动、无消耗、不占出手）：
- 制服ニャンコ / 閃忍ニャンコ / 魔女フタバ（R）：全队 毒·魅惑·束缚（+/眩晕）免疫。
- 神騎ハニーエル（R）：自身魔法免疫 + 全队 眩晕·束缚 免疫。
- **推论**：在魅惑/眩晕/束缚 重的 boss 战里，这种"免控领域"等于白送一个对策位，价值高于一次性解控。

### 观察 6：防御无视 / 贯通 = 独立乘区，对高防 boss 暴涨
伤害公式里防御按 `(1 - DEF/2000)` 衰减。无视防御是直接拿掉的独立乘区。
- 閃忍マユリ（R）必杀 **15× 无视防御**（自爆式单体核弹）。
- 神騎ハニーエル（R）必杀 **穿透蜂蜜魔免**（针对魔免敌人）。
- **推论**：这类对"高防/魔免"的 raid boss 有非线性收益，应单列推荐。

## 3. 第三步：我自己的评价框架（不依赖官方榜）

我定下 4 条**可验证**的打分维度，按权重排序：

1. **机制稀缺度 × 机制强度**（最高权重）
   拥有全游戏 ≤10 人的机制（不撤退 / 复活 / 全异常免疫 / 攻击增益 / 破防），且幅度经核验确实高。
2. **独立乘区叠加**（公式推导）
   伤害 = 攻击 × 连击 × (1−DEF/2000)/(1−MRES/2000) × (1+各增益%相加) × 必杀倍率。
   增益是**相加**的，所以"多一个不同类的增益来源"比"把单个增益堆更高"更划算 → 稀有增益辅助价值被放大。
3. **站场能力**（对抗核心失败条件）
   不撤退 > 异常免疫领域 > 持续治疗/减伤。
4. **满突成本**（养成铁律）
   满突★5 的 R ≫ 零突★1 的 SSR。对新手，把稀缺机制落在 R/SR 上是最高性价比。

注意：第 4 条只用于"新手核心"筛选；对"通用 S 级"我按机制强度排，不因稀有度扣分（SSR 满突后机制照样成立）。

## 4. 第四步：候选逐一核验（基于 _details.txt 原文）

我对约 30 个候选打印了完整 必杀技+固有效果 文本，确认幅度/条件后才下结论。节选关键发现：

- **ビートソニック・アキレス(SSR)**：不撤退 + 血量<20% 回 25~50% 最大体力(1次)。攻击仅 475（非攻击上限），但"不撤退"本身已极稀有 → S 级站场。
- **ブライドハルカ・リバース(SSR)**：不撤退 + 攻击 521(上限) + 必杀 10% 即死（失败叠攻击上限 50%）+ <10% 降仇恨。攻防一体强包。
- **閃忍マユリ(R)**：不撤退 + 必杀 **15× 无视防御**（自身承 100% 体力）。全游戏最暴力的单体自爆核弹，R 卡白送。
- **超昂閃忍ナリカ(SSR)**：自然体力消耗停在 25% + **复活**（火种）；双修 521/521/500。唯一复活位，泛用顶级。
- **体育祭のヤブルー(SSR)**：**全异常免疫**（全游戏独 1）+ 出战全队必杀+25% + 必杀全体 50%魅惑/75%束缚（巨型团队硬控）。唯一真·全免控核心。
- **妹の1024(SSR)**：普攻 80% 概率随机友军必杀+10%（自身同步）；必杀 场地速度+30% + 全队必杀+30%（叠 5 次）。最强充能核心之一。
- **真夏のイーイー(SSR)**：在场友军出战攻击+30%（盛夏+50/速度+25）；必杀横排 6×魔法 + 全队眩晕抵抗+50。攻击增益仅 3 人之一。
- **黒門天・屍寺炎斎(SSR)**：<30%/65% 双节点 每秒 5% 回血 + 防御+100%；必杀 10×魔法（存活攻击+30% 上限 150%）。攻击增益仅 3 人之一。
- **制服ニャンコ / 閃忍ニャンコ(SSR)**：在场全队 毒·魅惑·束缚（+/眩晕）免疫 + 爆发治疗/攻防速增益。免控领域 + 治疗二合一。

- **鬼の斗羽大洋(SSR)**：出战 敌方输出−25% / 我方+25%；必杀 **全体攻防−60%**（减益幅度罕见）。顶级破防减益。
- **アイドルの奉輪こもり(SSR)**：**撤退时**全队回 50% + 攻防+30%（死亡即全队大补）。独特的"退场收益"机制。
- **神騎ハニーエル(R)**：自身魔法免疫 + 全队 眩晕·束缚 免疫 + 必杀穿透蜂蜜魔免。R 卡里的魔免对策专精。
- **エスカ・アメイズ(R)**：必杀 全体 **必中魅惑**（魅惑免疫除外）——廉价的硬控对策。
- **閃忍クサリ(R)**：必杀 全体 **强制眩晕**（眩晕免疫除外）+ 束缚。廉价的硬控对策。
- **閃忍サイカ(R)**：出战 **敌方时停 2.5~4 秒**（全游戏独一份的"开局冻结"）+ 低速 3 人速度+25%（对闪忍彼岸花+300%）。机制独特。

## 7. v0.3 增补：副本/BOSS × 配队推理（用户要求结合各种副本/BOSS 与"5人上场+分队伍"）

### 7.1 我先纠正了自己对"分队伍"的理解
读 `raid.md` / `raid-formations.md`（**系统事实页，非推荐榜**）才明白：所谓"上场5人、可分队伍"在讨伐战里不是同场多队，而是**接力轮换**——体力每秒扣 2%（百分比，双防无效），单队 50 秒必退，所以高分打法是 `优先1(5)→优先2(15)→替补→星面50人` 多队接力。这直接推翻了 v0.2"只列5人"的呈现方式。

### 7.2 从 raid 机制推出的配队铁律（非官方推荐）
- **减伤率 debuff（降防）>> 攻击 buff**：面对 75% 减伤 BOSS，降防带来的伤害提升是攻 buff 的 **3 倍**（60%减伤时1.5倍）。→ 这**修正了 v0.2**：我把"攻击增益(3人)"列 S 级，其实在 raid 里降防手（破防/贯通14人）更核心。
- **单体 + 领域同名叠加**：同类多角色同款只取最高（浪费），但单体型与领域型叠加 → 一单体一领域最优。
- **必杀充能辅助 = 得分核心**（FEVER 中必杀次数决定分）；**默认带持续治疗**；**BREAK（确定点灯）比纯时停更值**（破防=眩晕+1.5倍+重置攻击）。

### 7.3 BOSS 参数 → 对策机制 → 角色匹配（独立推导）
我把 7 个 BOSS 的参数（伤害量/减伤率/异常抗性/破防灯数/特殊机制）逐一对照，得出每BOSS必需对策，再从 v0.2 已核验角色里匹配：
- 古纳冈：领域1%/s持续伤害 → **持续治疗**（制服ニャンコ/六の法杖セラフィール/魔女雫流）。
- 乌塔尔：小猫机制 → **全体攻击/全体异常必杀**清小猫（体育祭のヤブルー 全体魅惑+束缚 正好同时点灯）。
- 堕威大佛：高眩晕抗+破防灯仅3格 → **确定点灯**（エスカ・アメイズ R 必中魅惑、閃忍クサリ R 强制眩晕，无视抗性点灯）。
- 大往女：眩晕带束缚 → **束缚免疫领域**（制服ニャンコ/魔女フタバ R/神騎ハニーエル R）。
- 弗栗多：60%×4人极痛+双形态破盾+减速极高收益 → **减速debuff + 降防100%破盾 + 体力停止居座**（超昂奈理卡）。
- 黄金甜心：魔法减半 → 物理队优先或带"咬甜心王子"装备。
- 狂王：小狂王随从 → 全体必杀清随从。

### 7.6 「降防收益 = 攻 buff 的 3 倍」严格证明（用户点名要求论证）

**结论先说**：这不是我的发明，`raid.md`（系统事实页）原文就写了两条精确比例；且可从 `raid-buff-debuff.md` 的伤害公式严格推出。该"3 倍"指**同百分比幅度下，降防带来的"绝对伤害增量"是攻 buff 的 3 倍**（当 BOSS 减伤率 R=75% 时）。

#### (a) 公式来源（raid-buff-debuff.md）
副本最终伤害 = … × **攻击力提升倍率** × … × **BOSS减伤率削减系数** × …
且：`降低防御/降低闪避（敌方单体+领域合计上限50%）的总百分比，按比例削减副本BOSS的减伤率`。

#### (b) 数学推导
设 BOSS 减伤率 = R（如 0.75），基础裸伤（不含这两条）= `A·(1−R)`（A=基础攻击力×(其余乘区)）。
- **攻增益幅度 x**（倍率 `1+x`）：伤害 = `A·(1+x)·(1−R)`，绝对增量 `Δ_atk = A·(1−R)·x`。
- **降防幅度 x**（把 R 按比例砍到 `R(1−x)`）：BOSS减伤率削减系数 = `1−R(1−x)`，伤害 = `A·(1−R+R·x)`，绝对增量 `Δ_def = A·R·x`。

两者之比：`Δ_def / Δ_atk = (R·x) / ((1−R)·x) = R/(1−R)`。
- R=0.75 → 0.75/0.25 = **3 倍**。
- R=0.60 → 0.60/0.40 = **1.5 倍**。

#### (c) 与 wiki 原文一一对应（raid.md 直接陈述）
- "面对75%减伤BOSS，攻击增益效果与减伤降低收益比例 **2.5:7.5**；同等数值下，减伤降低带来的伤害提升是攻击增益效果的 **3 倍**。" → 7.5/2.5=3 ✓
- "面对60%减伤BOSS，攻击增益效果与减伤降低收益比例 **4:6**；同等数值下，减伤降低带来的伤害提升是攻击增益效果的 **1.5 倍**。" → 6/4=1.5 ✓
- 还说"仅减轻率最低的古纳冈（50%），攻击buff与减轻率debuff的价值相等" → R=0.5 时 R/(1−R)=1 ✓ 完全自洽。

#### (d) 关键前提与边界（避免误用）
1. **比较的是"同百分比幅度"**：每 1% 降防的边际价值 = R/(1−R) × 每 1% 攻 buff。是"单价"比较，不是"总收益"比较。
2. **修正：50% 上限只针对"降低闪避（回避buff）"，正常降防无此上限**。重读 `raid-buff-debuff.md` 明细表确认：
   - `降低防御` / `领域降低防御` 的数值列一路列到 **100%**，**没有 50% 封顶**（即"正常降防buff 没限制"）。
   - `降低闪避` 那一行才标 `上限50%敌方单体`（领域侧另有标注）。
   - 主句"降低防御、领域降低防御、降低闪避（敌方单体+领域效果合计上限50%）"的 50% 注，实际是挂在"降低闪避"上的，我先前把它误套到降低防御上。
   - 含义：降低防御能堆得比 50% 更高（表见 60/75/80/100%），实战"降防堆高 + 再叠攻 buff"的空间比我之前写的更大；wiki 也说"80%以上减轻率降低 + 攻击增益"——这与"降防无 50% 上限"一致。攻 buff 仍靠单体+领域+永久相加叠高。
3. **只适用于减伤率高的 BOSS**：乌塔尔(65%)/弗栗多/黄金甜心(75%) 优势巨大；古纳冈(50%) 两者等价；普通主线/EX BOSS 减伤率低，攻 buff 相对更划算。
4. ** raid 里双防无效、体力按百分比扣**——降防/攻 buff 都不影响生存，故纯比输出效率时此结论直接成立。

> 我 v0.3 在 reco-team.md / llm-recommend.md 里写的"75%减伤BOSS时降防收益是攻buff的3倍（60%时1.5倍）"即此结论，现已确认有公式+wiki 双重支撑，结论成立。

#### (e) 具体算例（A=1000 裸威力，攻 buff 与降防均取 50% 幅度）
D0 = 1000·(1−R)；攻buff50% = 1000·1.5·(1−R)；降防50% = 1000·(1 − R·0.5)。

| BOSS（R） | 裸伤 D0 | 只上攻buff+50% | 增量 | 只上降防50% | 增量 | 倍数(降防/攻buff) |
|---|---|---|---|---|---|---|
| 低减伤 30% | 700 | 1050 | +350 | 850 | +150 | 0.43× |
| 古纳冈 50% | 500 | 750 | +250 | 750 | +250 | **1.0×（相等）** |
| 堕威大佛/大往女/狂王 60% | 400 | 600 | +200 | 700 | +300 | **1.5×** |
| 乌塔尔 65% | 350 | 525 | +175 | 675 | +325 | 1.86× |
| 弗栗多/黄金甜心 75% | 250 | 375 | +125 | 625 | +375 | **3.0×** |

读法：R=75% 时，攻buff 只多打 125 点（250→375），降防却多打 375 点（250→625），375/125=3 倍。R越低差距越小，到古纳冈(50%) 两者完全相等；低于 50% 降防反而更亏。
补充（修正上限误读后）：本表降防取 50% 仅是"与攻buff同幅度"的对照；而**正常降低防御无 50% 上限**，表列到 100%。若 R=75% 把降低防御堆到 100%，BOSS 减伤率→0，伤害=1000·(1−0)=1000（裸威力全吃）；即便只堆到 80%，伤害=1000·(1−0.75·0.2)=850。所以实战"降低防御堆满 + 攻buff叠加"远强于表里 50% 对照，结论只会更偏降防。降低闪避（回避buff）才是被 50% 上限约束的那个。
实战可叠加（攻buff+降防 = 1000·1.5·(1−R·(1−x_def))），R=75%、x_def=50% 时 = 937.5，逼近 1000 裸威力。

**特征解析**（从 `char_data.json` 的 `stats_lv100`+必杀/固有效果日中文本正则提取 + `combat` 真实字段）：
`base=max(攻撃力,魔法力)`@lv100；`ult_mult`=必杀倍率（只认 canon「敵?(単体|横列|全体)N倍」，觉醒+取最大）；`def_down/atk_buff/dmg_up/guard` %；真实 `行動速度(sec)/必殺充填量(%)/連撃率(%)`；`flag`: heal/immune/no_retreat/revive/hardcc/dec_cc/slow。

**固定场景常量（Step3 用户确认，均一行可改）**：
- 伤害公式乘数：FEVER=3 / CRIT=1.25 / BREAK=1.5
- 固定装备套：3主=装备提升値+300；3副=贴片B8(敌防御-30%)/B1(攻+30%)/B3(速+20%)
- 固定觉醒强化：攻速+3%(=+0.03, 行动间隔除法生效) / 充能+15pt(加法并入必杀充填量)
- 固定 BOSS：R_ref=0.50（古纳冈类）· 体力-2%/s · 机制常亮
- 連撃阈值=60%（基础连击率 0/50/70 三档跳变）

**损伤频率模型（v0.6 核心，分数=秒伤）**：
```
interval     = 行動速度(sec) / (1 + 副装速20% + 觉醒速3% + 自身速buff)   # 行动间隔(秒)
interval_ult= interval × (1 + 連撃率)         # 连击使行动计量条不前进→必杀/普攻节奏变慢（连击惩罚）
atks/s      = 1 / interval_ult
charge_eff  = min(100, 必殺充填量% + 觉醒充15pt)
必杀casts/s = (charge_eff/100) / interval_ult
combo_mult  = 1 + Σ 連撃率ⁿ×decay(n), decay=0.8/0.6/0.4/0.3(≥4击)   # 连击追加伤害(不暴击)
red_coeff   = 1 - R_ref*(1 - min(1, def_down + 副装降防30%))
crit      = 1.25  if (atk_buff>0 or 副装攻30%) else 1.0
break_m   = 1.5   if hardcc else 1.0
base_hit  = (base+主装300) × (1+atk_buff+副装攻) × (1+dmg_up) × red_coeff
normal_DPS= (base_hit·crit + base_hit·(combo_mult-1)) × atks/s      # 基础击暴击，连击追加不暴击
ult_DPS   = base_hit × ult_mult × FEVER × break_m × 必杀casts/s
DPS_raw(c)= normal_DPS + ult_DPS
```
**辅助/生存分**（按机制稀缺度赋点，BOSS机制常亮→必须覆盖）：`UTIL = 100·复活 + 60·不撤退 + 40·免疫 + 35·奶 + 30·解控 + 25·硬控 + 30·guard`。
**综合强度**：`STRENGTH = 0.70·DPS_norm(0-100) + 0.30·UTIL_norm(0-100)`，分 **T0(前10%)/T1(前30%)/T2(前60%)/T3(其余)**。


### 11.2 公式改动（`_char_score.py` v0.8）
```
interval  = max(行動速度-2, 3) × (1 - 0.50) / (1 + 自身速buff)   # 火箭乘法，作用于觉醒后
red_coeff = 1 - R×(1 - min(1, 降防))        # 降防只剩角色 kit 自带（无 30% 打底）

crit      = 1.25 常驻（腰带全员带 → 全员一致，不影响相对排名）
```
常数：`EQ_ROCKET_SPEED=0.50 / EQ_BELT_ATK=0.50`（删 `MAIN_EQ_ATK/SUB_DEF_DOWN/SUB_ATK_BUFF/SUB_SPEED`）。
