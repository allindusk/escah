# 游戏机制理解（大模型阅读系统/装备/道具页后的整理）

> 来源：`site/zh/` 下已翻译的系统页（battle / getting-started / unique-effects / skills / equipment / raid-recommended）。
> 这是"理解层"，用户可在此纠正我的机制理解。

## 1. 战斗底层（battle.md）
- **体力(ST)**：随时间流失，归 0 角色撤退。⇒ 体力抑制/回复（仁王纳豆、治疗、不会撤退）决定能否站场。
- **行动速度**：最重要。3 秒角色≈6 秒角色的 2 倍出手次数。装备火箭引擎(物理)/咆哮猛虎(魔法)缩短冷却。
- **必杀充能效率**：SSR≈10%，R/SR≈7.5%；低于 10% 必杀明显更慢，低于 6% 单人难以发动。超昂装备/装备补丁可提。
- **必杀倍率（battle.md 原文表）**：単体 6→9 倍（觉醒强化时）；横一列（前排1+后排2）4→6 倍；全体（最多5体，无视"援护"）2→4 倍。
  ⇒ AoE 倍率低但覆盖多体；**raid BOSS 单体不倒下**，故 单体必杀倍率(9倍)在 raid 木桩上是"单位时间总伤害"最高的一类，全体必杀靠覆盖多体分摊，但 raid 木桩只有1体，全体必杀的"多体优势"在木桩上不兑现。
- **连击（連撃）机制（battle.md 精确事实，用户重点）**：
  - 连击率决定普通攻击时连续攻击的概率；每次连击伤害衰减 20%，下限 30%（即 80%→60%→40%→30%→30%…）。
  - **连击中「必杀充填量带来的必杀计量条增加」不发生**（"必杀充填量…連击中不发生"）；反击、连击中追加攻击时计量条也不增加。
  - 连击发生时行动计量条（☆）不前进，"连击发生过多会使行动周期变慢，结果必杀技发动变慢" → **连击输出角色必杀节奏更慢、必杀伤害在总分中占比应降低**（这就是用户要求的"连击输出必杀倍率伤害权重降低"的结构性依据）。
  - raid 中因敌人不倒下，连击暴击也不发生（"連撃不暴击"）；连击在 raid 往往偏负面，除非低连击率 FEVER 外多放1次必杀、或极度专精连击(20+连)伤害超2次必杀。
  - ⇒ **建模含义**：把输出角色分为 単体/全体/連撃 三类；連撃型（高连击率）的 必杀倍率 伤害权重下调，普通攻击连击伤害权重上调（连击是其主要输出手段）。
- **暴击（仅团队战/raid）**：raid 中赋予"命中buff"（攻击力提升）时，按效果量%触发暴击判定，必杀+普攻伤害 ×1.25；连击不暴击。⇒ 我方固定带攻击buff（副装B1 +30%）即稳定触发暴击，CRIT=1.25 进单角色分。
- **FEVER（狂热）**：raid 中充分培养的大半攻击者 FEVER 内可放 2 次必杀；部分有加速必杀手段的角色可能放第3次。⇒ FEVER=3 倍作为必杀伤害的常驻乘区（机制常亮）。
- **必杀充能效率（必殺充填量）**：每次普攻增加的必杀槽量；与行动速度协同极大。未强化：R/SR≈7.5%、SSR≈10%；低于10%必杀明显变慢，低于6%单人难发动。⇒ 行动速度(sec，越小越快，最快3s)与必杀充能效率(%)共同决定必杀释放频率 → 进 tempo 轴。
- **前排/后排**：近战(黄)只能前排，最多 3 前排；远程(蓝)可前/后。后排需≥2 远程才满 5 人上场。
- **属性(太阳/月/星)**：同属性攻击 1.2 倍；无石头剪刀布。阵营(战士/闪忍/神骑/魔女)用于特攻与固有效 buff。
- **异常状态**：中毒/魅惑/眩晕/咒缚。魅惑最危险（魅惑你方单位）；需免疫角色（闪忍喵子、制服喵子）或解除（六法杖塞拉菲鲁、女仆百合佩）。

## 2. 养成铁律（getting-started.md）★最重要★
- **满突破★5 的 R ≫ 零突破★1 的 SSR**。突破(限界突破)拉到★5 是性价比核心。
- 新手首要目标：角色兑换所换往期 R，★5 突破。官方点名新手核心：魔女雫(顶级治疗)、节拍偶像·玉木、节拍偶像·明惠、万圣节绮蕾、魔女哈皮。
- **助战(借用)是最强工具**：借高阶单位，无视属性限制。
- 装备优先级：火箭引擎/咆哮猛虎(速度) > 仁王纳豆(体力抑制) > 冲击腰带(攻魔) > 超级钻头(必杀槽) > 斗志十姐妹；超昂金(按阵营攻击)、圣剑科斯莫斯(超昂祭全能属性)。

## 3. 固有效果(unique-effects.md) 关键模式
- **阵营 buff**：艾斯卡蕾雅(战士+)、闪忍遥(闪忍+)、神骑艾克希尔(神骑+)、魔女雫(魔女+)——同阵营编队大幅增伤。
- **不会撤退**：体力 0 不撤退（节拍音速·阿喀琉斯、婚纱遥·逆转形态、盛夏遥、R真百合/FM77/玲奈/弗洛雷鲁、超昂闪忍知留香、盛夏风香）——站场输出的标志。
- **魅惑/异常免疫**：闪忍喵子"在场期间友军效果无效"(=免疫敌方魅惑等减益)；制服喵子全异常免疫；闪忍节喵(R)束缚免疫；和装塞拉菲鲁束缚免疫；婚纱·库鲁鲁眩晕免疫。
- **体力抑制/回复**：超昂·玛瑙、超昂闪忍成香、万圣节艾克希尔、女郎蜘蛛初音、八爪妖蛊初音等自带体力流失减缓。
- **速度/充能**：闪忍彩香(R)300% 速度辅助；神骑参宿四(R)全队充能；妹妹1024 顶尖充能+速度。

## 4. 装备(equipment.md) 核心
- 主+副共 6 格；副装备栏靠强化点数扩（无★数限制）。
- 速度系(火箭/猛虎,带★不叠加)、体力抑制(仁王纳豆,带★)、攻魔(冲击腰带/腰带逸品)、必杀槽(超级钻头/钻头逸品)、连击(连击纳豆—巴比伦尼尔专属优先)。
- 超昂金：按持有[战士/闪忍/神骑/魔女]人数提升攻/魔/防御/体力——阵容不齐则无用。
- 圣剑科斯莫斯：超昂祭角色拥有全部属性/特殊——妮露等核心队必备。
- 消耗品：甜心打火机(战斗不能全回复,讨伐战珍贵)、海马栖所(损坏加突破点)、眩晕帽(防眩晕)。
