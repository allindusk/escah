# 超昂大战 攻略 Wiki · 中日双语镜像站

把日文攻略 Wiki [「超昂大戦エスカレーションヒロインズ 攻略 Wiki」](https://escalationheroines.wikiru.jp/)
整套搬下来，逐句译成简体中文，做成**中日双语的静态攻略站**：
角色数据、必杀技 / 固有特效、觉醒与装备、Raid 与活动、道具清单、实测数据统计，都能在一个站里查。

**在线访问**

| 站点 | 地址 | 说明 |
|---|---|---|
| Cloudflare Pages | <https://escah.pages.dev/> | 全球 CDN，地址最短 |
| GitHub Pages | <https://allindusk.github.io/escah/> | 与代码仓库同源，国内访问可能偏慢 |
| 原站 | <https://escalationheroines.wikiru.jp/> | 内容与数值以原站为准 |

进站默认简体中文，右上角可切换「日文 / 中文」与「访问线路」；两个镜像内容完全一致，哪个快用哪个。

> 个人非商业爱好项目，**随缘更新**。中文为 AI 翻译 + 人工校对，难免生硬或漏译；数据有出入时请以原站为准。

## 站点里有什么

镜像 755 个页面（450 个角色详情页 + 257 个装备 / 剧情等子页 + 48 个主页面），约 3100 张图片；
每页都有日文原文与中文译文两版（部分译文仍在持续完善）。

| 栏目 | 内容 |
|---|---|
| **角色** | 角色一览（SSR / SR / R）、支援者、NPC、450 个角色详情页；必杀技一览、固有特效一览、可筛选分类一览；寝室场景一览、原画索引、声优一览、实装历史 |
| **游戏指南** | 新手指南、常见问题、实用小技巧、扭蛋 |
| **系统** | 战斗 → Raid（推荐角色 / 增益减益一览 / 编队示例）、B 宇宙、广域战与地图、歼灭战；界限突破、觉醒强化、等级上限提升、宝箱、交换所、角色交换所、图鉴收藏、商店（VIP 等级） |
| **装备与道具** | 装备一览、超昂装备、道具一览、道具价值速查表 |
| **任务与使命** | 主线剧情、全剧情实装顺序、主线任务、每日任务、任务一览、活动一览 |
| **其他** | 官方帮助中心、术语集、俗语集、Tips 一览、数据统计、更新记录 |

**比原站多做的事**

- **中日双语并排**：日文页保留原站原貌，中文页全站翻译（含正文、表格、技能说明）
- **角色浮窗**：鼠标悬停或点击角色名 / 头像，直接弹出属性与技能卡，不用跳页
- **表格增强**：全站表格支持表头排序、列筛选、全屏查看，横向长表可用 Shift + 滚轮横滑
- **图片灯箱**：点正文里的图片原地放大
- **阅读布局**：导航栏可切换超宽 / 标准宽度，随时收起左侧导航与右侧目录；阅读偏好会被记住
- **页面信息**：每页底部标注原站更新日、本次同步时间、翻译状态角标，并可一键跳回原站对应页
- **数据统计**：把攻略作者的实测数据（歼灭战报酬、D2P 扭蛋、战斗箱子掉落、宝箱开箱效率等 15 页）做成可排序表格
- **手机适配**：移动端专门排版，含悬浮目录与回到顶部

## 怎么用

### 只是想查资料

直接打开上面的在线地址即可，无需安装任何东西。想对照日文原文时点页面右上角的语言切换。

### 想在本地跑起来

需要 **Python ≥ 3.11**、**Node.js 20**、**Git LFS**（图片资产以 LFS 存管）。

```bash
git lfs install
git clone https://github.com/allindusk/escah.git
cd escah

pip install -r requirements.txt
pip install -e pipeline        # 安装后可用 escah-pipeline 命令
cd site && npm ci && cd ..
```

> 仓库带全站图片（Git LFS，约 200 MB+），首次 `clone` / `lfs pull` 会慢一些；
> 如果只想要页面结构和代码、暂时不要图片，可以 `GIT_LFS_SKIP_SMUDGE=1` 克隆后再按需 `git lfs pull`。

Windows 下可直接双击脚本：

| 脚本 | 作用 |
|---|---|
| `start-dev.bat` | 生成站点内容并启动开发服务器（热更新）→ <http://localhost:5173/escah/> |
| `start-site.bat` | 内容过期才构建，然后预览构建产物 → <http://localhost:4173/escah/> |
| `stop-dev.bat` / `stop-site.bat` | 停止对应服务 |

对应的手动命令（任意平台）：

```bash
python -m escah_pipeline.cli sync-site     # 由原站快照 + 译文生成站点内容
cd site
node build.mjs dev                         # 开发 5173
node build.mjs build                       # 构建到 site/.vitepress/dist
node build.mjs preview                     # 预览 4173
```

### 想同步原站的新内容（维护者）

```powershell
.\update.ps1          # 联网增量同步：抓取变更页 → 重解析 → 应用翻译
.\local-sync.ps1      # 快照已由 CI 抓好时：全程离线重建（parse → 译文回贴 → 站点）
```

改译文、补词表、批量精校等日常作业，请照
[`SOP_增量同步与翻译.md`](SOP_增量同步与翻译.md) 执行（含分阶段命令与踩坑清单）。

## 项目结构

```
escah/
├── pipeline/escah_pipeline/   Python 流水线：抓取 → 解析 → 翻译 → 生成站点内容
├── site/                      VitePress 双语站点（ja / zh）+ 前端组件与样式
├── glossary/                  日中词表：角色名、游戏术语、固定短语、保留原文名单
├── data/
│   ├── raw/                   原站 HTML 快照
│   ├── parsed/i18n/           译文真值（模板 + 双语 JSON，人工校对成果都在这里）
│   ├── assets/img/            全站图片（WebP）
│   ├── statdata/              攻略作者实测数据（数据统计页的数据源）
│   └── registry/              页面注册表与镜像计划
├── tools/                     辅助脚本（作业脚本在 tools/sop/）
├── start-*.bat / stop-*.bat   一键开发与预览
└── update.ps1 / local-sync.ps1
```

技术栈：Python 3.11+（httpx / lxml / BeautifulSoup / PyYAML）负责抓取解析与译文管理，
VitePress 1.x（Vue 3）生成中日双语静态站，GitHub Actions 负责抓取存档与部署。
