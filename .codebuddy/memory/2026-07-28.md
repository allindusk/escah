- **结果**：run 5124cef build+deploy 全绿；线上验证 `https://allindusk.github.io/escah/` 200、`zh/list-ssr.html` 200 且含「魔法少女瞳美」（翻译生效）。GH Pages 部署闭环打通：push main → Actions 自动 parse+sync-site+build → Pages 发布。
