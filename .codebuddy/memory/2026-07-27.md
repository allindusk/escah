- 根因：① `fetcher.parse_wiki_lastmod` 只匹配 `最終更新日時:` 形式（meta description），漏掉更通用的 `<div id="lastmodified">Last-modified: ...` 形式；② manifest 全站 408 页 `wiki_last_modified` 当初抓取时未被填（字段全 None）。raw 快照实际含该标记（`最終更新日時:` 46/60、`Last-modified:` 60/60）。
- 修复：① `fetcher.py` 的 `LASTMOD_RE` 改为同时匹配 `最終更新日時`/`Last-modified`，并放宽空格与秒数可选 → 覆盖率 100%。② 一次性回填 manifest：遍历 408 页读 `data/raw/<basename>` 重跑 `parse_wiki_lastmod`，填 406 条（2 条无 raw 快照、10 条 raw 无该标记仍空）。注意 manifest 的 `file` 字段写的是 `raw/...` 而真实路径是 `data/raw/...`，故用 basename 拼 `config.RAW_DIR`。
- 重跑 `sync-site` 重新生成 `page-times.json`（guide 47 / char 369，wiki 空 1+9），再 `node build.mjs build`（113s，detached 落 `tools/_logs/`）。dist 已含数据；4173 预览为静态读取 dist，浏览器硬刷新即可见。
- 注：今后 `cli update` 抓取时会用新正则自动填 `wiki_last_modified`，无需再手动回填。

## 搜索 0 结果修复 + tableEnhancer 表格结构错乱大修（2026-07-27 深夜）
- **搜索"点了没反应"根因**：`config.ts` 自定义 miniSearch `tokenize` 引用**闭包外**的 `const CJK_RE` —— VitePress 把 searchOptions 里的函数序列化(`toString()`)后在浏览器端 eval 重建（deserializeFunctions），闭包变量全部丢失 → 每次输入抛 `ReferenceError: CJK_RE is not defined`、永远 0 结果。修复：正则移入 `tokenize` 函数体内（`\uXXXX` 转义写法），并加注释警告"searchOptions 内函数必须自包含"。playwright 实测：搜「扭蛋」16 条结果，无报错。
- **表格结构错乱三症状根因链**（数据层 raw↔ja↔zh 416 页全站表结构逐行逐格比对 **0 差异**，问题全在前端 `tableEnhancer.ts`）：
  1. "同一行分两行"：`normalizeTable` 只把**第一行**搬进 `<thead>`，双行表头（全站 1138 表）第二行留 tbody；rowspan **不能跨 thead/tbody 行组**生效 → `rowspan=2` 表头被浏览器截断错位；且第二表头行被 `dataRows` 当数据行参与排序。修复：新增 `headerRowsOf()`（开头连续全 th 行=表头块）整块搬入 thead。
  2. "多出一列/错位"：`buildColumnFilterRow` 按 `header.children.length`（首行 DOM 子数）建筛选行，表头含 colspan（2184 表）时列数不够/对不上；且插在 `header.nextSibling`=插进双行表头**中间**。修复：新增 `headerGrid()` 网格展开算 totalCols 与 th→叶列映射；筛选行插在**表头块之后**；无可筛选列时不再插空行。
  3. 数据区含合并单元格（333 表）时 `children[idx]≠列号`：排序/筛选/删列全错位。修复：新增 `bodyHasSpans()`，此类表**禁用**排序+列筛选（保结构优先）；`trimEmptyLeadingColumns` 遇任何 rowspan 直接跳过；`markSpecialColumns` 改"按单元格"处理（img→minWidth、>40字→escah-long），不再按列索引映射。
  4. `makeSortable` 改用 headerGrid 映射：`colSpan>1` 的分组表头不给排序，叶 th 按真实列号排序。
- 验证：annihilation 页（最复杂：24×rowspan 表头+双行表头）DOM vs frag 36 表/535 th/5733 td 完全一致；双行表头 theadRows=2 完整入 thead。build 77.5s EXIT-0。
