## 左侧导航栏 sidebar 分隔符（SIDEBAR_TREE）实线
- 分隔符节点用 `_SB_DIV = "__SB_DIV__"`，`_sb_node` 返回 `{"text":"—","link":f"/{locale}/characters.html#__SB_DIV__"}`，custom.css 用 `.VPSidebarItem a[href$="__SB_DIV__"]` 隐藏文字 + `border-top:1px solid` 画实线。
- **致命根因（铁律）**：VitePress **客户端渲染时会直接丢弃「纯 hash 链接」`link:"#__SB_DIV__"` 的 sidebar item**（DOM 里 0 个 `<a>`，CSS 选择器永远失效，分隔符不可见）。必须用「真实存在页面 + 锚点」`/zh/characters.html#__SB_DIV__` 作 link，VitePress 才会渲染成 `<a href="/escah/zh/characters.html#__SB_DIV__">`。空文本 `""` 也会被跳过，故 text 用可见的 `"—"`（再被 CSS 隐藏）。
- 中间节点（角色一览/战斗等）不要折叠：去掉 `_sb_node` 与 `_write_sidebars` 里的 `collapsed`（全部展开）。
- **自检 DOM 方法（无需让用户刷新）**：用系统 Edge 无头 dump 渲染后 DOM 验证 item 真实渲染：`& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu --no-sandbox --virtual-time-budget=8000 --dump-dom "http://localhost:4173/escah/zh/characters.html" | Out-File -Encoding utf8 _dom_dump.html`，再 `[regex]::Matches($dom,'<a[^>]*SB_DIV[^>]*>')` 看数量（应为 6 = 角色组2+系统组3+任务组1）。**永远用 dump-dom 实际验证渲染结果，不要只 grep 内联 JSON 字符串——JSON 含数据不代表 DOM 渲染出来。**

## items.html 宝箱变「昂扬花苞」根因 + 救回 5 个损坏文件（重大事故）

### 现象
- `items.html#content_1_1` 的 `treasure-box.html` 链接文字由「宝箱」变成「昂扬花苞」。

### 真因（系统性，非偶发）
- `i18n.py` 的 `render_locale` 对每个节点级 key 调 `_name_override(ja)`，再到 `_correct_text`（含 `_CORR_RE.sub`）。

- **Bug B（黄金蜜）**：raid.html 列表页 th 显示「黄金蜜」而非「黄金哈尼」。根因=wiki 原文拼写变体 `ゴールンデンハニー`（多一个 ン），raid.json `key304` 的 zh 被填成「黄金蜜」。`_name_override` 查 `ゴールデンハニー`（少ン）不命中。修复=①`raid.json key304.zh` 烘焙为「黄金哈尼」；②`glossary/names.yaml` 补 `"ゴールンデンハニー": "黄金哈尼"`（覆盖变体）。渲染期 `_sub` 现会命中 names 覆盖。
- **全站审计**：写 `_audit_links.py` 扫 dist 所有 `<a class=internal-link>`，查 href 值含 `target=`/空格 即破损。修复后 internal-link 24826 个破损 0、黄金蜜残留 0、黄金哈尼 42 页生效。

## region 折叠块「整块消失」bug 修复（2026-08-03 晚，用户报 raid-005）
- **现象**：raid-005 点某个展开态的 rgn-button 想折叠，点击后整块内容（含标题行）都不见了。

## region 折叠块方案最终定论（在「整块消失」修复之后的多轮迭代）
> 前述「整块消失」节描述的是第一版方案（强制折叠），之后用户连续纠正两轮，最终方案如下，未来模型以此为准。
- **用户纠正1**：默认展开块不要改成折叠 → 曾改"无 expanded 保留原站 inline"，但导致默认折叠块点击展开后无法重新折叠。
- **用户纠正2**：默认展开块也要给用户折叠的权利 → 最终方案：渲染时（`_initRgnBase`）把「初始 content 是否可见」直接同步成 `expanded` 类（默认展开块渲染即带 `expanded`、默认折叠块不带），之后**唯一真值就是 `expanded` 类**（`_syncRgn` 只按它设 content/desc/图标）。这样默认展开块首次点击即折叠、默认折叠块可双向 toggle，且不再"整块消失"。
- 验证（jsdom，raid-005 全 6 块）：第5期初始展开→点击1折叠→再点展开；其余默认折叠块点击展开→再点折叠，全部正确。
- ⚠️ 教训：rgn 这类"初始脏状态"问题，**不要把基准态单独存变量和 expanded 类并存**（会互相打架），应把初始态收敛进唯一真值（expanded 类），toggle 只切这一个变量。
