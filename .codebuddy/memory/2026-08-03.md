## 左侧导航栏 sidebar 分隔符（SIDEBAR_TREE）实线
- 分隔符节点用 `_SB_DIV = "__SB_DIV__"`，`_sb_node` 返回 `{"text":"—","link":f"/{locale}/characters.html#__SB_DIV__"}`，custom.css 用 `.VPSidebarItem a[href$="__SB_DIV__"]` 隐藏文字 + `border-top:1px solid` 画实线。
- **致命根因（铁律）**：VitePress **客户端渲染时会直接丢弃「纯 hash 链接」`link:"#__SB_DIV__"` 的 sidebar item**（DOM 里 0 个 `<a>`，CSS 选择器永远失效，分隔符不可见）。必须用「真实存在页面 + 锚点」`/zh/characters.html#__SB_DIV__` 作 link，VitePress 才会渲染成 `<a href="/escah/zh/characters.html#__SB_DIV__">`。空文本 `""` 也会被跳过，故 text 用可见的 `"—"`（再被 CSS 隐藏）。
- 中间节点（角色一览/战斗等）不要折叠：去掉 `_sb_node` 与 `_write_sidebars` 里的 `collapsed`（全部展开）。
- **自检 DOM 方法（无需让用户刷新）**：用系统 Edge 无头 dump 渲染后 DOM 验证 item 真实渲染：`& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu --no-sandbox --virtual-time-budget=8000 --dump-dom "http://localhost:4173/escah/zh/characters.html" | Out-File -Encoding utf8 _dom_dump.html`，再 `[regex]::Matches($dom,'<a[^>]*SB_DIV[^>]*>')` 看数量（应为 6 = 角色组2+系统组3+任务组1）。**永远用 dump-dom 实际验证渲染结果，不要只 grep 内联 JSON 字符串——JSON 含数据不代表 DOM 渲染出来。**
