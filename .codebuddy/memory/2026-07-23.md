## 本 turn：修复 zh_patch.py 损坏（SyntaxError）+ 全站重译验证
### 损坏根因（两处）
1. 早前一次全局 `\"`→`"` 替换把**字符串字面量内** HTML 属性的转义引号也去掉了
   （`class="..."`/`href="..."`/`style="..."`/`data-mtime=""` 等），导致 Python 字符串提前闭合 → SyntaxError。
2. 插入的 battle 通用术语块（约 1271–1564 行）被放在了 `JA2ZH` 的闭合 `}`（1268 行）**之后**，
   成了模块级非法语句（battle 条目 `"助っ人": "助攻者",` 不在任何 dict 内）。

### 修复方法（tools/_fix2.py，字符级状态机 walker）
- code / dq(双引号串) / tdq / sq / tsq 状态机；**仅在已处于双引号字符串内**时，对 `attr="..."`
  模式的属性引号重新转义（用 `attr_name_before` 校验 `=` 前是属性名、用 `attr_depth` 计数配对开/闭），
  **绝不误伤代码里的 kwarg 字符串**（如 `read_text(encoding="utf-8")`）。
- 属性闭合引号三种情形都覆盖：`"` 后接 `>`/`/`；后接 `空格+属性名=`；后接 `空格+"` 且 `attr_depth>0`（空值 `""` 与非空值 `url" "`）。
- 之后把 battle 块从 `}` 之后重定位回 `JA2ZH` 内部（`}` 之前）。
- 用 `ast.parse` 校验通过；`zh_patch.py` 现已健康可运行。
