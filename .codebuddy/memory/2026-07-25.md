- 结果：49/49 页有日文，共 36,190/63,723 条待翻译块。TXT ~2.6MB，JSON ~11.8MB。
- 用户要求补充 characters/ 子目录页：改为扫描 data/parsed/ja/{,characters/} 两个目录，输出到 _texts_for_translation/{,characters/}。
- 最终：418 页（49 顶层 + 369 角色）全部有日文，共 105,697/167,748 条待翻译块，836 个输出文件（418 .txt + 418 _map.json）。
- ⚠️ 脚本运行需 `$env:PYTHONIOENCODING="utf-8"`（Win GBK 控制台编码会崩在打印日文 slug 处）。
- 回注方式：翻译完后对照 [N] 与 map，构造 JA2ZH[原日文]=译文 写入 zh_patch.py，zh_patch.patch() 用 html.replace(原日文,译文) 精确定位回标签——原日文即锚点，不需知道标签。
- 与 _api_pipeline.py 的区别：_extract_texts 产出是静态文件供人工/工具翻译；_api_pipeline 是实时调 LLM API 并在 inject 阶段自动构造 JA2ZH。两者注入目标一致（都是 JA2ZH 词表）。
