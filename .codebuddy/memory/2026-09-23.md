## 游戏机制调研：可与单体/场地攻击buff再叠加的「非buff扱い」自增攻

**结论（重要，后续翻译/编写 wiki 需留意）**
攻击buff存在**三层可加算**，第三层即为查询目标：

伤害公式出处 `data/raw/バフ・デバフ能力キャラ　一覧まとめ.html`：
```
レイドにおける最終ダメージ＝
(基礎攻撃力(魔法力)＋覚醒上昇値＋装備上昇値＋サポーター上昇値)
×攻撃アップ倍率(キャラ対象＋フィールド対象＋累積効果・永続効果)
×与ダメアップ倍率(キャラ対象＋フィールド対象)
×…
```
→ 「キャラ対象」(单体) + 「フィールド対象」(场地) + **「累積効果・永続効果」(第三层)**。

配套规则出处 `data/raw/よくある質問.html`：
- 同种buff复数 → 只取最高值（不叠加）
- キャラ対象buff 与 フィールド対象buff → **加算**
- 「攻撃力/魔法力アップ」抬高的是伤害计算基数；「与ダメアップ」是结算后再乘

第三层统称「累積効果・永続効果」，wiki 描述关键词为
「バフ扱いではない」「永続」「アイコンの付くバフとは別枠で加算」「他の攻撃バフと共存」
→ 不会被バフ解除/バフ無効消掉，也不与其他攻撃アップ上書き。

**具备第三层效果的已知角色**（分被动/主动，均出自各角色页 raw 日文）
被动(固有効果/覚醒)：超昂閃忍イノリ、エスカルビー・アステライズ、ハルカ・リバース、
ビートアイドル・ノドカ、ビートノーブル・カノン、ブライドエスカ・ルビー、ブライド・クルル、
幻忍コテツ、正月エスカレイヤー・リバース、視えずの黒子サナギ、閃忍ハナコ、閃忍ゲッカ、
閃忍ユキカゼ、魔女カミーユ、聖夜イノリ、真夏のアズエル、深窓の令嬢ステアール、バビロニア・ニル
主动(必殺/スキル)：バレンタインリコリス、黒門天・屍寺炎斎、レジェンド・エスカレイヤー、
レガリアの超昂神騎ユリエル、ブライドエスカレイヤー・リバース

最直白点名"在单体+场地之上加算"的原句 = 「超昂閃忍イノリ」页：
「固有効果の攻撃アップはバフ扱いではないためバフ解除の対象にならず、全体攻撃アップやフィールド攻撃アップにさらに加算して計算する。」

## 实操：如何确认「无图标加攻」已发动（重要，玩家高频痛点）

核对结论：**事后无法从 UI 确认，全站无一处记载别枠加攻会反映到ステータス画面。**

1. 唯一视觉线索 = 发动瞬间的增益特效，過ぎたら見えない。
   `ブライドハルカ・リバース`：
   > アイコンは表示されないが、発動時にはメリット効果のエフェクトは出る。
   （注：「メリット効果」在其他页面都是"有利"的普通名词，并非UI术语）

2. wiki 编辑者也抱怨看不到（证明确实没有可靠 UI）：
   `バレンタインリコリス` 评论：「画面上のアイコンに上昇量も表示してほしいわ…ただ、この手の能力アップはアイコン付かないから今…」
   `ハルカ・リバース` 评论：「固有効果はバフ表示ないし純粋にステータスか与ダメージが上がってるっぽい」

3. ステータス画面 = 基礎/詳細ステータス（连击率・出撃速度・必殺充填等），不含别枠加攻。
   `真夏のチルカ`：「詳細ステータスはスタン発動率・出撃速度・必殺充填量が上乗せされており（あとは同値）」

4. 实用做法＝**数触发条件**（各角色的wiki都给了确定配置与上限）：
   ビートストーム・ハヅキ 连击発生時+1%最大50%／エスカルビー 通常攻撃ごと且**连击・反击不加**／
   バビロニア・ニル 通常攻撃ごと最大50%(必殺と合わせ自身のみ最大250%)／
   ビートノーブル・カノン デバフ解除ごと／聖夜イノリ 必殺5回まで／
   ハルカ・リバース 撃破数(通常10体・覚醒6体→30%)／深窓の令嬢ステアール 反擊回数ごと+10%最大+50%

5. 条件型＝盯条件本身，可用**关联图标间接判断**。
   `神騎カースエル`：スタミナ50%切のラインは目視では判断が難しいため**継続ダメージのデバフアイコンの有無で判断すると良い**
   同理：幻忍コテツ(継続ダメージ中)／視えずの黒子サナギ(ヘイト減少中)／超昂閃忍チルカ(スタミナ以下の間)

6. 终极验证＝**伤害反推**，且 wiki 给了可直接套的加算公式。
   `ブライドハルカ・リバース`：
   > 必殺技の攻撃アップが50％ある時に攻撃アップバフ50％を受けた場合、攻撃アップ100％の状態になり、
   > 必殺技の攻撃アップが50％ある時に攻撃ダウンデバフ99％を受けた場合、攻撃ダウン49％の状態になる。

7. 坑：发动顺序会影响是否吃到加成，且视觉上看不出来。
   `レイドおすすめキャラ`：サポーター久世七暴等で戦闘開始からそのまま必殺を撃つと**固有効果発動前で攻撃アップが乗らない**。

## 判据辨析：不能只看「有没有写时间」

用户提出推论「没写时间的攻击加成 ⇒ 可与限时buff叠加」，核查结论：**方向基本对，但措辞不准**。

真正的判据是**有没有 buff アイコン（是否バフ扱い）**，不是有没有时间词汇。
官方定义出处 `エスカアメイズ・ファンタスマ`：
> バフ/デバフとはキャラにアイコンが付く攻撃、防御、命中、回避、速度、与ダメ、スタン抵抗率を上下する効果のこと
> キャラにアイコンが付かない効果はバフ/デバフではない

最贴近用户推论的正面表述 `ハロウィンニコール`：
> 固有の秒数記載の無い効果はバフアイコンの付かない永続効果。バフアイコンの付く効果とは加算になる。

**但反方向不成立**——带条件/期间的照样可能别枠：
- 超昂閃忍チルカ：「既定スタミナ以下の間だけ適応される効果で、バフではないためアイコンは表示されない」
- 幻忍コテツ：「継続ダメージ中に攻撃力30％アップ」＋「バフ扱いではない強化」
- 視えずの黒子サナギ：「ヘイト減少中の攻撃アップ」＋「アイコンの付くバフとは別枠で加算」
- 聖夜イノリ：「自身が必殺技を5回使用するまでの間、自身の攻防50%アップ」

**同一技能内两种可并存**（最佳对照）`ビートストーム・ハヅキ`：
「自身の攻撃1％アップ(最大50％)」无时间→别枠永続；
「各連撃３撃目時、１０秒間、自身の回避５０アップ」有时间→普通buff。
→ 必须逐条看效果，不能按整条技能判断。

可靠方向只有一条：**写了「N秒間/効果時間N秒」⇒ 一定是带图标的普通buff，同类取最高**。
反向（没写秒数 ⇒ 别枠）只是强信号，非必然。

## 方法备忘
`data/raw/*.html` 是 PukiWiki 页面源码，技能说明多为表格单元，
直接 grep 会因为 tag→换行的拆散而漏掉原文；可靠做法是
「去标签后拼成整串 + 围绕关键词滑动窗口取上下文」。
