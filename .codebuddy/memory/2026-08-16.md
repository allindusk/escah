# 2026-08-16

## 右侧目录（DocOutline）不跟随阅读滚动（已修复）
- **现象**：用户报所有页面右侧目录（自定义树状大纲 `DocOutline.vue`，挂在 `Layout.vue #aside-top`）的高亮项随阅读移动，但目录栏自身的滚动条不会自动滚动，高亮项移出目录可视区后看不见。
- **根因**：`.escah-doc-outline` 是 `position:sticky + max-height + overflow-y:auto`（有独立滚动条），但 `DocOutline.vue` 只有 `IntersectionObserver` 高亮逻辑（`activeId` 跟随），**缺少让目录自身滚动以跟随 active 项**的代码（VitePress 默认 outline 有此行为，自定义版漏了）。
- **修复**（`site/.vitepress/theme/components/DocOutline.vue`）：新增 `navEl` ref 绑定 `<nav>`；`ensureActiveVisible()` 在 `activeId` 变化时（watch）调用——计算 active `<a>` 相对目录栏的位置，超出可视区则只调整 `nav.scrollTop`（块居中），**只滚目录栏、不影响页面主体**。加 `watch(activeId, () => nextTick(ensureActiveVisible))`。
- **验证**：`sync-site` 不需（仅前端组件），直接 `build.mjs build` 通过。theme bundle 含新逻辑。
- **版本**：1.2.7→**1.2.8**，changelog 加用户视角条目（右侧目录跟随滚动）。改动未 push（待用户指令）。
- ⚠️ 经验：自定义替换 VitePress 默认 outline 时，别漏掉"active 项自动滚入大纲可视区"这一默认行为；且滚动必须限定在目录容器内部（`scrollTop`），否则 `scrollIntoView` 会连带滚动整个页面。
